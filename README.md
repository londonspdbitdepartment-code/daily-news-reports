# Daily News Reports

Daily news intelligence reports generated by the [sci-research](https://github.com/haiou312/sci-research) plugin's `/daily-news-intelligence` pipeline. Published as static files via GitHub Pages.

## Access

- **Index of available dates and files**: `https://londonspdbitdepartment-code.github.io/daily-news-reports/index.json`
- **Single report**: `https://londonspdbitdepartment-code.github.io/daily-news-reports/{date}/{filename}`

Example:

```
https://londonspdbitdepartment-code.github.io/daily-news-reports/2026-05-06/日本每日热点新闻-2026-05-06.md
```

## Structure

```
{YYYY-MM-DD}/
  ├── 中国每日热点新闻-{date}.md / .docx
  ├── 美国每日热点新闻-{date}.md / .docx
  ├── 日本每日热点新闻-{date}.md / .docx
  ├── 韩国每日热点新闻-{date}.md / .docx
  ├── 英国每日热点新闻-{date}.md / .docx
  ├── 欧洲每日热点新闻-{date}.md / .docx
  └── {date} 简报.docx                # SPD Bank branded daily briefing
```

## index.json schema

```json
{
  "dates": ["2026-05-06", "2026-05-05", ...],
  "reports": {
    "2026-05-06": [
      { "name": "...", "url": "2026-05-06/...", "size": 1234 }
    ]
  },
  "updated_at": "2026-05-07T..."
}
```

## Frontend usage

```javascript
const idx = await fetch(
  'https://londonspdbitdepartment-code.github.io/daily-news-reports/index.json'
).then(r => r.json());

const latest = idx.dates[0];
const files = idx.reports[latest];

const md = await fetch(
  `https://londonspdbitdepartment-code.github.io/daily-news-reports/${files[0].url}`
).then(r => r.text());
```

CORS is open (`Access-Control-Allow-Origin: *`) on `*.github.io`.
